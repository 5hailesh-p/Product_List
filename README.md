# Product Listing & Filtering App

A responsive React + TypeScript application that displays a list of products with powerful filtering, searching, and sorting capabilities. Built as a frontend coding assessment project to demonstrate component design, state management, and UI development skills.

---

## 🔗 Live Demo
https://product-list-omega-ten.vercel.app/

## 💻 GitHub Repository
https://github.com/5hailesh-p/Product_List

---

## 📌 Features

- Product listing in responsive grid layout
- Search products by name (case-insensitive)
- Filter by multiple categories
- Filter by price range
- Real-time UI updates
- Loading and error handling states
- Clean and reusable component structure
- Fully responsive design (mobile + desktop)

---

## 🛠 Tech Stack

- React (Vite)
- TypeScript
- Tailwind CSS
- React Hooks (useState, useEffect, useMemo)
